# Simulated self-driving car: digital twin, synthetic edge cases, verified planning stack
Pure NumPy + Matplotlib. `make test` (smoke tests), `make results figures` (about 15 min, 2 cores), `make pdf` (or upload this folder to Overleaf, main file `main.tex`).
Layout: `code/` (all Python), `sections/` (report, one file per topic), `results/`, `figures/`, `logs/`, `build/` (generated C policy).
Not executed here: `code/carla_bt.py` (needs CARLA), real datasets, on-target embedded timing.
